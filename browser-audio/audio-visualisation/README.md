# Audio Visualisation and Voice Control

Historical experimental source using p5.js, p5.sound, Meyda and p5 speech recognition. It expects personally supplied WAV files under `assets/sounds/`: `your_captcha_word.wav` (the original answer is `hello`) and `Ex2_sound1.wav`, `Ex2_sound2.wav`, `Ex2_sound3.wav`. Supply a compatible p5.SpeechRec library; the original archive omitted it.

This source has overlapping global draw/canvas handlers and needs further refactoring before it can be described as a verified demo. The audio challenge is illustrative and offers no real authentication protection. Commercial tracks and private recordings are excluded.
