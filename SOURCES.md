# Sources and preparation

Recovered personal Colab notebooks and submission ZIP. Rice bitstream functions were extracted into a CLI without claiming a new compression algorithm. Preparation added round-trip checks and synthetic media generation. Browser libraries are third-party p5.js/p5.sound, with upstream headers retained. Original music, private voice recordings and model weights are excluded. Some historical prototypes still require missing inputs.

Prepared with AI assistance in November 2026. Source and framework credits remain part of the release. Descriptive project names replace internal submission filenames in the public navigation. No new blanket licence is applied to third-party code or datasets.

Bundled p5.js distributions were minified for this release with version notices retained.
